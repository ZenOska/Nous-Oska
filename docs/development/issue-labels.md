# Suggested issue labels

Create these labels in the GitHub repository as project work begins.

| Group    | Labels                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------- |
| Phase    | `phase: 0`, `phase: 1`, `phase: 2`                                                                   |
| Area     | `area: core`, `area: ui`, `area: browser`, `area: security`, `area: testing`, `area: infrastructure` |
| Type     | `type: feature`, `type: bug`, `type: task`, `type: docs`                                             |
| Priority | `priority: high`, `priority: medium`, `priority: low`                                                |

Add phase labels as the roadmap advances. Labels are GitHub repository settings and are not created by files in this repository.
