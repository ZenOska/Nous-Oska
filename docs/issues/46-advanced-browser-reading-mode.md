# Issue #46: Phase 6 : Advanced Browser - Reading Mode

- **State**: PLANNED / ROADMAP
- **Milestone**: Phase 6: Advanced Workspace & Productivity
- **Labels**: `enhancement, renderer, phase-6`

---

## Overview

Implement a distraction-free Reading Mode that strips ads, menus, and sidebars from articles, presenting clean typography with adjustable fonts and theme colors.

---

## Scope & Boundaries

### In Scope

- Address bar reader mode toggle appearing on article pages.
- Readability content extraction engine (extract title, body, author, date).
- Customizable typography (serif, sans-serif, font size, line spacing).
- Dark, light, sepia, and OLED black reading themes.

### Out of Scope

- Text-to-speech read aloud (Phase 7).

---

## Acceptance Criteria (Definition of Done)

- [ ] Reader mode icon activates automatically on long-form articles.
- [ ] Clicking reader mode displays stripped article in clean format.
- [ ] Adjusting font size and theme persists across reader sessions.
- [ ] Unit tests verify article extraction accuracy.
